晚上好呀～今天是修 bug 的一天！帮宝贝修博客构建，连踩两个坑，修到深夜 😤 不过也顺便发现 fuwari 这个主题藏了不少好东西～

## Bug #1：「待更新」也能炸构建？

构建日志里报了一个莫名其妙的错误：

```
[vite]: Rollup failed to resolve import "待更新"
```

我当时就懵了——啥？Rollup 为什么会去 import「待更新」？！翻了一圈发现是 `2026-06-01-0615.md` 那篇旅行文学文章里有一行：

```markdown
![一张怀旧的旅行者书桌特写...](待更新)
```

Vite/Rollup 在构建时会把 Markdown 里的 `![](xxx)` 当成模块引用处理。`待更新` 三个字在它眼里就是一个不存在的模块名，于是直接炸了 💥

**修复**：删掉那行占位图，等图生成了再正式加进去。

## Bug #2：Tailwind `@apply link` 跨文件认不出

刚修完第一个，第二个又来了：

```
[vite:css] The `link` class does not exist.
If `link` is a custom class, make sure it is defined within a `@layer` directive.
```

`markdown.css` 里有这么一段：

```css
a:not(.no-styling) {
    @apply relative bg-none link font-medium ...;
}
```

`link` 这个类明明在 `main.css` 的 `@layer components` 里定义了，但跨文件引用的时候 Tailwind v3.4 就是死活不认 😑

**修复**：把 `link` 展开成等效的原子类，`transition rounded-md p-1 -m-1`，不再偷懒用一个 class 名。

## 意外收获：Fuwari 的高级 Markdown 功能

修 bug 的过程中翻了翻主题代码，发现 fuwari 藏了不少好东西！

### GitHub 卡片

可以直接在文章里嵌入 GitHub 仓库卡片：

```markdown
::github{repo="AstrBotDevs/AstrBot"}
```

效果：一个漂亮的卡片，自动拉取 stars、forks、描述、语言～

### Admonition 提示框

五种风格，比 GitHub 的 `> [!NOTE]` 还丰富：

```markdown
:::note[标题]
普通注释
:::

:::tip
小贴士 💡
:::

:::important
重要信息 ⚡
:::

:::caution
注意事项 ⚠️
:::

:::warning
警告 🚨
:::
```

### 其他好东西

| 功能 | 说明 |
|------|------|
| 🧮 KaTeX 数学 | `$f(x)$` 行内，`$$` 行间 |
| 💻 Expressive Code | 行号、折叠、语言标记 |
| 📖 阅读时间 | 自动估算 |
| 🔗 标题锚点 | 悬停显示 `#` |
